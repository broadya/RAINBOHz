# Contributing to RAINBOHz

RAINBOHz is an early-stage research project and, for now, a one-person
effort. The design is still moving quickly, so this is not yet a good time to
contribute code.

- **Issues are welcome.** Bug reports, questions and ideas all help. Please
  open an issue.
- **Pull requests are not being sought yet.** Unsolicited changes may not be
  merged, because the part they touch may be about to change. If you would
  like to work on something, open an issue first so we can discuss it.

This will change as the project matures, and this file will say so.

## Building and testing

The developer guide in [README.md](README.md#developer-guide) covers setup.
In short, everything runs from the root `Makefile`: `make help` lists the
targets and `make test` runs the whole test suite.

## Conventions

[AGENTS.md](AGENTS.md) holds the project's conventions: C++ style (C++ Core
Guidelines), Architecture Decision Records in [docs/adr/](docs/adr/), and the
SPDX licence line every source file starts with.

RAINBOHz is licensed under the [Apache License 2.0](LICENSE). Any
contribution you submit is licensed under the same terms, as section 5 of the
licence describes.

A code of conduct will be added when the project opens to contributions.

## Security
